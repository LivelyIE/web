# AIB Decreases Rates By Up To 0.35%

## 17 Oct 2026

AIB decreases its Higher Value 4 Year fixed rates by up to 0.35%. The new rates are available immediately.

| Product | New Rate | Change |
| :--- | :----: | :----: |
| **Loan-To-Value 90% or Less** | | |
| 4 Year (250k+) | 3.25% | -0.35% |
| **Loan-To-Value 80% or Less** | | |
| 4 Year (250k+) | 3.2% | -0.30% |
| **Loan-To-Value 50% or Less** | | |
| 4 Year (250k+) | 3.15% | -0.25% |
